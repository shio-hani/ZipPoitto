# ZIP Guard

ZipPoitto は、ZIPファイルの解凍だけに特化したシンプルなWindowsアプリです。

高機能な解凍ソフトは便利ですが、初めて使う人にとっては「どれを押せばいいの？」と迷ってしまうことがあります。

ZipPoitto は必要な機能だけを残し、「ZIPを解凍する」という操作をできるだけ簡単に行えるよう設計しました。

---

## 特徴

- ZIPファイルのみ選択可能
- ドラッグ＆ドロップ対応
- 解凍先を自動作成
- シンプルで初心者でも使いやすい画面

---

## 動作環境

- Windows 10 / 11

---

## 使い方

1. アプリを起動します。
2. ZIPファイルをドラッグ＆ドロップ、または選択します。
3. 「解凍」を実行します。
4. ZIPファイルと同じ場所にフォルダが作成されます。

---

## Windows Defender の警告について

Windows Defender SmartScreen の警告が表示される場合があります。これは個人開発のアプリであるためで、コード署名がないアプリでは一般的な表示です。
内容を確認したうえで実行してください。
